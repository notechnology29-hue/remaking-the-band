# Solo MVP Roadmap

Source: GDD §9. Each milestone should produce a playable artifact and answer
a concrete design question. Defining pressure to preserve at every stage:
**Stamina vs Trust vs RNG**, public narrative control, tactical performance.

## Milestone 0 — Scaffold (this repo, as-is)

React + Vite project structure, design tokens, and data-driven folder
layout. No game logic. Validates: the project runs and the structure matches
the GDD's layer breakdown (Presentation / State / Content / Audio /
Packaging).

## Milestone 1 — The Decision Engine

A text-first React prototype of the Daily Call Sheet and Studio Phase:
stamina, trust, creative friction, genre blending, gear modifiers, RNG.

**Validates:** weekly choices create meaningful trade-offs before visual
polish.

## Milestone 2 — The Stage Grid

A CSS-grid tactical stage with clickable movement, AP, MP, audience
pressure, hazards, one high-risk 3D RNG dice action, and the 5%/0% stamina
thresholds.

**Validates:** the Weekend Set piece is readable, tense, and playable rather
than a cinematic interruption.

## Milestone 3 — The Weekly Episode

Connect Pre-Production & the Daily Call Sheet, Directing the Camera Crew,
the Spin Room, and the Weekend Set piece into one complete episode loop.

**Validates:** preparation, footage, editing, and tactical performance carry
consequences across phases.

## Milestone 4 — The Pilot Episode

Package the connected loop with one premade parody band, a small Custom Band
Canvas flow, one Rival Band, one Studio Upgrade, the UI-era transition,
four-stem audio (Howler.js), and the first end-state decision.

**Validates:** tone, onboarding, the replayable consequence chain, and
suitability for mobile / Steam / web-first testing.

---

Solo production rule: validate rules, state transitions, readability, and
fun before investing in finished visuals, extensive audio, complex 3D
environments, or the complete roster.
