# Utils

Shared helpers that don't belong to a specific system:

- `dice.js` — the 3D RNG dice resolver (visible probability + modifiers, per
  GDD §6 "Combat Language").
- `stamina.js` — the 5%/0% stamina threshold checks used across the Compound,
  Studio, and Weekend Stage (GDD §4).
- `format.js` — shared display formatting (percentages, currency, AP/MP).
