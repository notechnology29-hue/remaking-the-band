# Audio

Howler.js four-stem dynamic audio (GDD §8): management tension, studio
groove, broadcast spectacle, and tactical danger. Stems enter, leave, or
intensify independently based on phase, network pressure, audience pressure,
and high-risk actions.

Not wired until Milestone 4 (Pilot Episode). Audio files live in
`public/assets/audio/`; this folder holds the mixer/controller logic only.
